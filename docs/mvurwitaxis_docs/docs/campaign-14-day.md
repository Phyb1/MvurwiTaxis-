## Daily execution (every day of the campaign, not just posting days)

- Post that day's content once — WhatsApp Status is the primary
  channel, cross-post to Facebook/Instagram where it's easy.
- Personally contact 3–5 new drivers (see `campaign-content-bank.md`
  for DM variants — rotate them, don't send the same one twice to the
  same person).
- Follow up with 2–3 warm leads from previous days.
- Ask at least one existing driver for a referral, every single day —
  don't save this for one dedicated day, it compounds faster spread
  out.
- Log every contact in `campaign-tracker.md` the same day: source,
  and where they are in contacted → interested → signed up → verified
  → active.
- Update the driver count anywhere it appears in that day's post before
  it goes out — a stale number undercuts the "real progress" framing
  the whole campaign leans on.

## What success looks like

Don't judge the fortnight by likes. Track the funnel:
**contacted → interested → signup started → registered → verified →
recently active.** A campaign that gets 15 signups but only 6 verified
and active isn't a win yet — see `operations-manual.md`'s verification
procedure and get through that backlog before calling Day 14 a success.
