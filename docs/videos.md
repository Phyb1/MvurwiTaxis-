MvurwiTaxis — Video Concepts
Same sequencing rule as the rest of the strategy: driver-recruiting videos now, passenger-awareness videos only once the directory has enough real drivers in it to survive being seen. Every video's job is to show the code working, not explain it — screen-record real taps, real WhatsApp opens, real fare numbers.

All Shorts, vertical (9:16), under 45 seconds, captions burned in, Shona/English mixed narration to match how drivers actually talk in the group posts you've been replying to. Low file size — audience is on mobile data.

Phase 1 videos — for drivers
1. "This is what your customers see" (recruiting hook)
0–3s: Phone screen, MvurwiTaxis homepage loading — "Taxis available in Mvurwi"
3–15s: Scroll through 3–4 driver listings (use your Verified drivers) — tap one, show the WhatsApp button, show it opening a real chat
15–25s: Cut to text on screen: "Free to list. You only pay 20c if we send YOU a customer."
25–35s: Signup page loading, cursor filling name/car — "2 minutes"
End card: signup link, 3 seconds held (long enough to screenshot)
2. "One link instead of retyping every day" (speaks to the exact behavior you're replying to)
Open with a real screenshot of a "Taxi available 24/7, call/app" style post (yours or a generic mockup, not someone's real number without permission)
Voiceover: "Sound familiar? You post this every day, in every group."
Cut to MvurwiTaxis profile page: "Post it once. It stays up."
End card: signup link
3. Driver testimonial (once you have 1–2 signed up drivers willing to be filmed)
10–15 seconds, driver in their own words: how they signed up, whether they've gotten a lead yet, one honest line
This is the single highest-trust asset you'll have — real drivers see a real driver, not you
Use as a reply to future DM outreach, not just a public post — "here's what [driver name] said" lands harder than a generic pitch
Phase 2 videos — for passengers (hold until 15–20 drivers listed)
4. "What's the real price to Harare?" (fare board proof)
0–5s: Someone asking that question — text on screen or a quick voiceover of the actual rank argument
5–20s: Screen-record scrolling the live fare board
20–30s: "No more guessing." — end card with the URL
This one's evergreen — re-cut with updated numbers whenever the fare board changes, don't need a new concept each time
5. "Request Any Taxi" demo
0–5s: Passenger standing somewhere, phone out, tapping "Request Any Taxi"
5–20s: Cut to a driver's phone getting the notification (split-screen or two clips edited together)
20–30s: Driver replying on WhatsApp
Text overlay: "Every available driver gets notified. First to reply gets you."
End card: URL
Posting notes
One video per WhatsApp Status/group per the existing rule — don't flood, rotate concepts across groups the way the text posts already do.
Reuse the same phone-screen footage across videos where you can (the homepage load, the fare board scroll) — cuts filming time down to just the new bit each time.
Pin whichever driver-recruiting video performs best to the top of your WhatsApp Business catalog or channel, if you're using one, so DM leads can watch it before you even finish pitching.
