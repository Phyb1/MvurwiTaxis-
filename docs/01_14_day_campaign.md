# MvurwiTaxis — 14-Day Driver Recruitment Campaign v2

Current position: 5 taxis listed
Campaign target: 15–20 drivers
Primary CTA: List your taxi at https://www.mvurwitaxis.co.zw/
Campaign theme: FIRST 20 DRIVERS

## Messaging pillars
1. Get found — public driver profile.
2. Get requests — direct messages, WhatsApp and Request Any Taxi.
3. Get notified — push/email request alerts.
4. Start free — $0 listing + 3 free leads/month.
5. Build trust — verified driver status.

## Daily execution
- Post one main WhatsApp Status/social post.
- Personally contact 5–10 potential drivers.
- Follow up with interested drivers.
- Ask existing drivers for 1–2 referrals.
- Record: contacted → interested → registered → verified → active.

## Important
Do not claim that MvurwiTaxis has a large network, guaranteed passengers, guaranteed income, or guaranteed trip volume. The current network is 5 listed taxis, so use that real number as social proof.
